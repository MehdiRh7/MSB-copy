پیشنهاد ← جلسه ← مصوبه ← امضا ← ابلاغ ← اجرا ← صحه‌گذاری ← پیگیری — همراه با هوش مصنوعی و گردش کار پویا

## اجرا

**پیش‌نیاز:** Node.js 20+

```bash
npm install
npm run dev          # http://localhost:3000
```

نسخه تولید (فایل‌های ساخته‌شده + پراکسی هوش مصنوعی روی یک سرور):

```bash
npm run build
npm start            # PORT=3000 به‌صورت پیش‌فرض
```

## انتشار روی Vercel

پروژه آماده انتشار روی Vercel است (`vercel.json` + توابع `api/ai/*` برای پراکسی هوش مصنوعی):

1. در vercel.com ← **Add New → Project** ← مخزن GitHub را Import کنید (تنظیمات Build خودکار از `vercel.json` خوانده می‌شود).
2. در **Settings → Environment Variables** کلیدها را اضافه کنید (`GEMINI_API_KEY` و/یا `OPENROUTER_API_KEY`، ...).
3. هر برنچ یک آدرس Preview جداگانه می‌گیرد؛ برای انتشار یک برنچ خاص، در **Deployments** آن را Deploy کنید یا برنچ را به Production Branch تبدیل کنید.

## هوش مصنوعی

سامانه می‌تواند از یکی از سه ارائه‌دهنده **Gemini**، **DeepSeek** یا **Grok** استفاده کند. انتخاب ارائه‌دهنده، مدل و قابلیت‌های فعال **فقط توسط مدیر سیستم** در «تنظیمات ← هوش مصنوعی» انجام می‌شود.

| ارائه‌دهنده | مدل رایگان پیش‌فرض | کلید |
|---|---|---|
| Gemini | `gemini-2.5-flash` (سطح رایگان Google AI Studio) | `GEMINI_API_KEY` |
| DeepSeek | `deepseek/deepseek-chat-v3-0324:free` از طریق OpenRouter | `OPENROUTER_API_KEY` (یا `DEEPSEEK_API_KEY` برای اتصال مستقیم) |
| Grok | `x-ai/grok-4-fast:free` از طریق OpenRouter | `OPENROUTER_API_KEY` (یا `XAI_API_KEY` برای اتصال مستقیم) |

> فهرست مدل‌های رایگان را خود ارائه‌دهنده‌ها تعیین می‌کنند و ممکن است تغییر کند؛ نام مدل در تنظیمات قابل ویرایش است.

کلیدها را در فایل `.env.local` قرار دهید (نمونه: `.env.example`). همه درخواست‌ها از پراکسی سمت سرور (`server/aiProxy.ts`، مسیر `/api/ai/chat`) عبور می‌کنند؛ کلید هرگز به مرورگر کاربران ارسال نمی‌شود. اگر کلیدی تنظیم نشده یا سرویس در دسترس نباشد، **موتور هوشمند محلی** (قاعده‌محور) پاسخ می‌دهد و این موضوع روی هر پاسخ با برچسب مشخص نمایش داده می‌شود.

قابلیت‌ها:

- **فرمان سریع (Ctrl+K):** جابه‌جایی، جست‌وجو و انجام کار با یک جمله یا فرمان صوتی فارسی
- **دستیار گفت‌وگومحور:** پاسخ تحلیلی روی داده‌های همان کاربر (با حفظ سطح دسترسی)
- **نوشتن پیشنهاد از یک جمله** و تشخیص پیشنهاد تکراری
- **تحلیل پیشنهاد برای مدیرعامل:** خلاصه، نقاط قوت، ریسک‌ها، پرسش‌های کلیدی و توصیه
- **زمان‌بندی هوشمند دستورکار** داخل بازه جلسه
- **پیش‌نویس خودکار صورت‌جلسه** از نتایج بندها و مصوبات
- **دستیار ثبت مصوبه:** متن اجرایی، مسئول، واحد، اولویت و مهلت
- **پیش‌بینی ریسک تأخیر مصوبه** (امتیاز قابل توضیح + توصیه)
- **نگارش گزارش پیشرفت و متن پیگیری**؛ رسمی‌سازی، خلاصه و تکمیل هر متن؛ دیکته صوتی
- **خلاصه هوشمند روزانه** در داشبورد و **گزارش تحلیلی مدیریتی** در گزارش‌ها

قابلیت‌های مرحله دوم:

- **جستجوی مفهومی:** «هر چیزی درباره امنیت داده» مصوبات هم‌مفهوم را پیدا می‌کند (نتایج همیشه پرونده واقعی‌اند)
- **خواندن پیوست‌ها:** خلاصه، نکات کلیدی، تصمیم‌های لازم و اعداد مهم PDF / Word / متنی
- **ضبط جلسه:** گفتار زنده به متن (Chrome/Edge)، فایل صوتی، صورت‌جلسه رسمی و مصوبات پیشنهادی
- **استخراج مصوبه از متن** با مسئول، مهلت و اولویت و ثبت یک‌کلیکی
- **پیشنهاد نتیجه بندها از گفتار جلسه** (تصویب / رد / مشروط / موکول / ارجاع ...) با جمله مبنا؛ **ثبت فقط با تأیید دبیرخانه برای هر بند**
- **بررسی تناقض و تکرار** پیش از ثبت مصوبه
- **پیشنهاد زمان جلسه** بر اساس جلسات ثبت‌شده اعضا
- **هشدار پیشگیرانه** برای مصوبات پرریسک و **اعلان لحظه‌ای** (بین تب‌ها + اعلان دسکتاپ)

## امضا، داشبورد و اسناد

- **امضای دیجیتال رمزنگاری‌شده (ECDSA P-256):** روی چکیده متن مصوبه/ابلاغیه؛ اعتبارسنجی، تغییر متن پس از امضا را نشان می‌دهد. (کلید در مرورگر؛ اتصال به گواهی رسمی و توکن سخت‌افزاری نیازمند سرور است.)
- **داشبورد قابل شخصی‌سازی** برای هر کاربر
- **اسناد رسمی با سربرگ** (نشان، شماره، تاریخ، پیوست، پاورقی) با خروجی **PDF و Word**

## گردش کار پویا

برای هر جلسه (یا به‌صورت قالب برای هر نوع جلسه، در «تنظیمات ← قالب‌های گردش کار») تعیین می‌شود:

- **تأیید دستورکار:** یک یا چند نفر، با منطق «همه»، «یک نفر کافی» یا «به ترتیب»
- **تأیید صورت‌جلسه** پیش از نهایی‌سازی (اختیاری)
- **امضای مصوبات:** امضاکنندگان اختصاصی، ترتیبی یا همزمان — یا همان سه امضای سراسری
- **امضاکننده ابلاغیه** همان جلسه

ویرایش هم با فرم و هم با **طراح گرافیکی (کشیدن و رها کردن)** انجام می‌شود. **گردش مصوبات پیشنهادی** (بررسی و تأیید نهایی) هم به همین شکل قابل تنظیم است.

جلسات قبلی و جلساتی که گردش اختصاصی ندارند دقیقاً مثل قبل کار می‌کنند (تأیید مدیرعامل و سه امضای سراسری).
